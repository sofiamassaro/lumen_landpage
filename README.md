# LUMEN — Landing page

> **Não mostra o processo — traduz.**
> O cliente entende cada passo sozinho e o advogado recupera seu tempo.

Landing page do **LUMEN**, SaaS que traduz as movimentações processuais em linguagem clara. O produto tem um painel web para o advogado e um app para o cliente dele.

A página é **desacoplada** da aplicação. É feita em HTML e CSS puros: sem framework, sem build e sem JavaScript.

Projeto Multidisciplinar Integrador (PMI) · Análise e Desenvolvimento de Sistemas · UNICESUSC
Autora: **Sofia Di Domenico Massaro**

---

## Público

| Quem | Papel |
| --- | --- |
| Advogado autônomo e escritório de pequeno porte | Cliente pagante: assina o LUMEN |
| Cliente pessoa física do escritório | Usuário final: acompanha o processo pelo app |


## Identidade visual

| Elemento | Valor |
| --- | --- |
| Navy (dominante) | `#15294B` |
| Latão (acento) | `#A67C3D` |
| Marfim (fundo) | `#F5F3ED` |
| Títulos | Spectral 700 (Google Fonts) |
| Texto | Inter 400–600 (Google Fonts) |

A página tem tema claro e tema escuro, conforme a preferência do sistema (`light-dark()`). O layout é responsivo, com quebras em 900 px e 640 px.


## Limitações atuais
